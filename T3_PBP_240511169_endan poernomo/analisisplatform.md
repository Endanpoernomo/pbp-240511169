# Analisis Perbandingan Platform: Web, Desktop, dan Mobile

Dokumen ini berisi analisis komparatif antara platform pengembangan Web, Desktop, dan Mobile berdasarkan arsitektur, teknologi, alur distribusi, serta kelebihan dan keterbatasannya.

| Aspek                       | Platform Web                                                                                                                                                                                         | Platform Desktop                                                                                                                                                                                        | Platform Mobile                                                                                                                                                                                                                                |
| :-------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Arsitektur**              | Berbasis _Client-Server_ melalui protokol HTTP/HTTPS. _Front-end_ berjalan di _web browser_ pengguna dan berkomunikasi dengan server/API untuk pengolahan data.                                      | Standalone/Monolitik atau _Client-Server_ lokal. Beroperasi secara langsung di atas lapisan Sistem Operasi (_Native OS API_) dengan akses penuh ke _hardware_.                                          | Arsitektur terisolasi (_App Sandboxing_) pada OS seluler. Berjalan berbasis _event-driven_ dan umumnya mengonsumsi _REST API_ / _GraphQL_ dari server backend.                                                                                 |
| **Bahasa Utama**            | **Front-End:** HTML5, CSS3, JavaScript / TypeScript (React, Vue, Angular).<br>**Back-End:** Node.js, PHP, Python (Django/FastAPI), Java (Spring Boot).                                               | C++ (.NET/Qt), C# (.NET WPF/WinForms), Java (Swing/JavaFX), Python (PyQt), Rust, Electron (JS).                                                                                                         | **Android:** Kotlin, Java.<br>**iOS:** Swift.<br>**Cross-Platform:** Dart (Flutter), JavaScript (React Native).                                                                                                                                |
| **Distribusi & Deployment** | Di-deploy ke _Web Hosting_, _VPS_, atau _Cloud Server_ (AWS, InfinityFree, Vercel). Didaftarkan melalui domain dan langsung diakses lewat URL.                                                       | Melalui berkas penginstal (_Installer_) seperti `.exe` / `.msi` (Windows), `.dmg` / `.pkg` (macOS), `.deb` / `.AppImage` (Linux), atau Microsoft Store.                                                 | Melalui mekanisme distribusi toko digital seperti Google Play Store dan Apple App Store, atau penginstalan manual paket APK / IPA.                                                                                                             |
| **Keunggulan**              | 1. Aksesibilitas tinggi tanpa perlu instalasi.<br>2. _Cross-platform_ secara alami (dapat dibuka di OS apa saja selama ada browser).<br>3. Pembaruan instan (_zero-client update_).                  | 1. Performa komputasi sangat cepat dan responsif.<br>2. Dapat bekerja secara luring (_full offline mode_).<br>3. Akses penuh ke _file system_, GPU, dan memori RAM lokal.                               | 1. Memanfaatkan periferal seluler (Kamera, GPS, Biometrik, Accelerometer).<br>2. Fitur _Push Notification_ untuk _engagement_ pengguna.<br>3. Desain antarmuka portabel dan ramah sentuhan (_touch-friendly_).                                 |
| **Keterbatasan**            | 1. Sangat tergantung pada kestabilan koneksi internet.<br>2. Akses ke perangkat keras lokal sangat dibatasi oleh keamanan _browser_.<br>3. Performa komputasi berat kalah dibanding aplikasi native. | 1. Memerlukan proses instalasi manual pada setiap perangkat target.<br>2. Proses pembaruan (_update_) aplikasi lebih sulit disebarkan ke pengguna.<br>3. Keterikatan tinggi pada spesifikasi OS target. | 1. Proses publikasi harus melewati kriteria peninjauan ketat (_review app store_).<br>2. Sumber daya perangkat (kapasitas baterai & kapasitas RAM) terbatas.<br>3. Kompleksitas penyesuaian berbagai variasi ukuran layar (_screen fragment_). |
| **Contoh Aplikasi**         | Figma (Web), Spotify Web Player, Wikipedia, Gmail Web.                                                                                                                                               | Adobe Photoshop, Blender, VLC Media Player, Laragon, WinBox.                                                                                                                                            | TikTok, Mobile Legends, Shopee, Telegram Mobile, DANA.                                                                                                                                                                                         |
